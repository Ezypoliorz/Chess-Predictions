## **Chess predictions**
#### Predicting the outcome of a chess game using XGboost

Uses a decision tree with XGboost to predict the result of chess games, based on the players' names and elo.
The model is first trained on data from The Week In Chess (https://theweekinchess.com/twic) and then tested on new data from the same database.

You can first run the main.py script, as it coordinates all the others.
